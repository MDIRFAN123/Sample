Challenge Identified

As the next enhancement, we are looking to extend the tool to support URL extraction from PDF content, including scanned PDFs where OCR is required.

During our initial evaluation, we identified a few OCR-related challenges, particularly with:

Very small text
Blurry or low-quality text
Low-contrast text
URLs split across multiple lines
Complex backgrounds or image noise

These scenarios can impact the accuracy of URL extraction.

Proposed Next Step – Phase 2

We propose enhancing the existing tool with an OCR-based text extraction capability and evaluating the appropriate approach to improve URL extraction accuracy across these scenarios.

We have also attached a document outlining the OCR-related issues and identified scenarios for reference.

The existing QR Code functionality is already deployed, so the OCR-based URL extraction can be taken forward as the next phase of the tool enhancement.

Please share your thoughts on the proposed approach and recommendations for taking the OCR/URL extraction capability forward.
