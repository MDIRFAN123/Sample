PDF QR CODE EXTRACTOR
NON-TECHNICAL USER MANUAL

Document purpose
================

This guide explains how to use the PDF QR Code Extractor without requiring any technical knowledge.

The tool finds QR codes inside a PDF document. It shows the page where each QR code was found, a picture of the QR code, and the information stored inside it.


1. What you need
================

Before you begin, make sure that:

• You have access to the PDF QR Code Extractor in a web browser.
• The document you want to scan is a PDF file.
• The PDF is no larger than 30 MB.
• You have a stable connection to the application.

You do not need to install any software on your computer to use the web application.


2. What the tool can do
=======================

The tool can:

• Scan every page of a PDF for QR codes.
• Find more than one QR code in a document.
• Show the page number where a QR code was found.
• Display a cropped preview of the QR code.
• Show the information stored in the QR code.
• Recognize common information types such as Wi-Fi details, contact cards, email addresses, phone numbers, JSON data, and text.
• Search the results by their contents.
• Sort results by PDF page number.
• Open valid website links in a new browser tab.
• Switch between light and dark display modes.


3. Supported files
==================

Supported file type:

• PDF documents with a .pdf filename extension

Maximum file size:

• 30 MB

The tool does not accept Word documents, Excel files, images, ZIP files, or other file types directly. If your QR code is in another document type, first save or export that document as a PDF.


4. Opening the application
==========================

1. Open the application link provided by your organization.
2. The “PDF QR Code Extractor” page will appear.
3. The first screen contains an area for selecting or dropping a PDF.

If the application does not open, check your connection and confirm that you are using the correct link. Contact your application administrator if the problem continues.


5. Selecting a PDF
==================

You can select a PDF in either of the following ways.

Method A — Browse for a file

1. Select “Browse PDF.”
2. Find the PDF on your computer.
3. Select the file.
4. Select “Open.”

Method B — Drag and drop

1. Find the PDF on your computer.
2. Drag the file into the area marked “Drag & drop your PDF here.”
3. Release the file inside the marked area.

After a valid PDF is selected, its name and size will appear. Scanning begins automatically; there is no separate Start button.


6. File checks
==============

The application checks the selected file before uploading it.

If the file is not a PDF, you will see:

“Only PDF files are supported.”

Select a file with the .pdf extension and try again.

If the file is larger than 30 MB, you will see:

“The PDF must be 30 MB or smaller.”

Reduce the PDF size or divide it into smaller PDF files before trying again.


7. Understanding the scanning screen
=====================================

While the PDF is being checked, the scanning screen displays:

• Progress percentage — the approximate percentage of pages completed.
• Scanning Page — the number of completed pages compared with the total number of pages.
• Pages Processed — the number of pages checked so far.
• QR Codes Found — the number of QR codes found so far.
• Elapsed Time — how long the current scan has been running.

The scan may take longer when:

• The PDF contains many pages.
• Pages contain large or detailed images.
• QR codes are small, rotated, blurry, or low contrast.
• Several users are scanning documents at the same time.

Keep the application page open until the scan finishes. Closing or refreshing the browser page may interrupt your view of the current scan.


8. Scan completion
==================

When scanning finishes successfully, the application displays “Scan Complete.”

The summary shows:

• Pages — the total number of pages in the PDF.
• QR Codes — the total number of QR codes detected.
• Scan Time — the total processing time.

The detailed results appear below the summary.


9. Understanding a QR result
============================

Each result card can contain:

• QR code preview — a cropped picture of the detected QR code.
• Page number — the PDF page where the QR code was found.
• Payload type — the general type of information stored in the QR code.
• Payload details — the actual text or data stored in the QR code.
• Open Link — shown only when the stored information is recognized as a valid website address.

“Payload” simply means the information stored inside a QR code.

Examples of payload types include:

• Text — normal text, a website address, or another unclassified value.
• Wi-Fi — network connection details.
• vCard — contact information.
• Email — an email address or email instruction.
• Phone — a telephone number instruction.
• JSON — structured data used by some systems.


10. Viewing complete QR details
==============================

1. Select a QR code preview.
2. A details window will open.
3. Review the page number, payload type, QR preview, and complete payload.
4. Select the X button to close the details window.

You can also press the Escape key to close the window.

Keyboard users can move to a QR preview and press Enter or the Space bar to open it.


11. Opening a website from a QR code
====================================

If the QR code contains a valid website address, an “Open Link” option appears.

1. Check the displayed address carefully.
2. Select “Open Link.”
3. The website opens in a new browser tab.

Safety reminder:

QR codes can contain links to unsafe or misleading websites. Only open a link when you trust the document and recognize the destination. Do not enter passwords, payment details, or personal information on an unfamiliar website.

If “Open Link” is not shown, the stored information was not recognized as a valid website address. You can still read the payload details.


12. Searching the results
=========================

Use the search box when the document contains many QR codes.

1. Select the “Search by payload” field.
2. Type part of the text you want to find.
3. The result list updates automatically.

The search is not case-sensitive. For example, searching for “example” can find “EXAMPLE,” “Example,” or “example.”

If no results match, the application displays “No Matching QR Codes.” Clear the search field to show all detected results again.


13. Sorting the results
======================

Use the page sorting list to change the order of results.

• Page: Low to High — shows results from the beginning of the PDF first.
• Page: High to Low — shows results from the end of the PDF first.


14. Moving between result pages
===============================

The application shows up to 12 QR results on one results page.

When more than 12 results are available, page controls appear below the result cards.

• Select a page number to move directly to that results page.
• Select the left arrow to move to the previous results page.
• Select the right arrow to move to the next results page.

These are result-list pages and are different from the page numbers in the original PDF.


15. Scanning another PDF
========================

1. Select “Scan Another PDF.”
2. The application returns to the file-selection screen.
3. Browse for or drag and drop the next PDF.

The previous results are removed from the screen when the application resets for another scan.


16. Light and dark modes
========================

Use the theme button in the top-right area of the page to switch between light and dark modes.

The application remembers your selection in the same browser when browser storage is available.


17. When no QR codes are found
==============================

If the scan finishes but no QR codes are detected, the application displays “No QR Codes Found.”

This may mean:

• The PDF does not contain a QR code.
• The QR code is extremely small.
• The image is blurry, damaged, or very low contrast.
• Part of the QR code is covered or cut off.
• The QR code is distorted.
• The PDF uses an image format or layout that makes detection difficult.

Suggested actions:

1. Open the original PDF and confirm that the QR code is visible.
2. Zoom in and check whether the QR code is clear and complete.
3. Obtain a higher-quality version of the PDF if possible.
4. Try a PDF containing a larger, sharper version of the QR code.


18. Troubleshooting
===================

Problem: “Only PDF files are supported.”

Cause: The selected file is not recognized as a PDF.

Action: Select a file ending in .pdf. If the source is another document type, export it as PDF first.


Problem: “The PDF must be 30 MB or smaller.”

Cause: The selected file exceeds the size limit.

Action: Compress the PDF or divide it into smaller PDF files.


Problem: “Unable to upload the PDF.”

Possible causes: The connection was interrupted, the application is unavailable, or the server rejected the upload.

Action: Check your connection, return to the scan screen, and try again. Contact the administrator if repeated attempts fail.


Problem: “Scan unsuccessful” or “The PDF could not be processed.”

Possible causes: The PDF is corrupt, protected, incomplete, or contains content the application cannot read.

Action: Confirm that the PDF opens normally in a PDF reader. Save a new copy and try again. Contact the administrator if the problem continues.


Problem: Scanning appears to be taking a long time.

Possible causes: The PDF has many pages or contains large images.

Action: Keep the page open and allow the scan to finish. If it never progresses, return to the scan screen and try again with a smaller PDF.


Problem: A QR code is visible in the PDF but was not found.

Possible causes: The code is too small, blurred, incomplete, distorted, or has poor contrast.

Action: Use a clearer or higher-resolution source PDF. If possible, enlarge the QR code in the source document before exporting it again.


Problem: The QR preview is unavailable, but payload details are shown.

Cause: The code was decoded, but the application could not create or display its preview image.

Action: Use the displayed payload information. The decoded result may still be valid even without a preview.


Problem: “Open Link” is not displayed.

Cause: The QR payload is not a recognized web address or did not pass the application's link checks.

Action: Read the payload details. Copying information should follow your organization's data-handling rules.


Problem: The page was refreshed and the scan or results disappeared.

Cause: The current interface does not provide a scan-history screen.

Action: Select and scan the PDF again.


19. Privacy and safe use
========================

PDFs are uploaded to the application for processing, and cropped QR preview images may be created. The application does not provide a user-facing delete button or a history page.

Before uploading a document:

• Confirm that you are allowed to upload it.
• Follow your organization's privacy and information-security policies.
• Avoid uploading confidential, personal, financial, medical, or restricted documents unless this application has been approved for that information.
• Ask your administrator how long uploaded PDFs and QR previews are retained.

Treat decoded QR content as untrusted until you have checked it. In particular, inspect website addresses before opening them.


20. Good-quality QR code recommendations
========================================

For the best results, use PDFs where QR codes are:

• Sharp and in focus.
• Large enough to see clearly.
• Fully visible with no missing edges.
• Surrounded by a clear blank margin.
• High contrast, preferably dark on a light background.
• Not covered by text, stamps, folds, or other graphics.
• Not excessively stretched or distorted.


21. Quick reference
===================

To scan a PDF:

1. Open the PDF QR Code Extractor.
2. Select “Browse PDF” or drag and drop a PDF.
3. Wait for scanning to finish.
4. Review the QR result cards.
5. Use search, sorting, or result-page controls when needed.
6. Select a QR preview to see complete details.
7. Select “Scan Another PDF” when finished.


22. Getting help
================

Contact your application administrator or support team when:

• The application does not open.
• Uploads repeatedly fail.
• A valid PDF repeatedly produces a processing error.
• The application stops making progress.
• You need information about document retention or privacy.
• You believe the displayed result is incorrect.

When reporting a problem, provide:

• A short description of what happened.
• The error message shown on screen.
• The approximate time of the attempt.
• The PDF page where the QR code appears.
• The browser you were using.

Do not send a confidential PDF to support unless your organization's policy allows it.
